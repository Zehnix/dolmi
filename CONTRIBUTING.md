# Contributing to Dolmi

Thanks for helping. Bug reports and pull requests are welcome at https://github.com/Zehnix/dolmi.

## Before you open a pull request

- Run the tests: `venv\Scripts\python.exe -m pytest -q tests/test_helpers.py` and `venv\Scripts\python.exe tests/test_webview_bridge.py`.
- Keep changes focused, and use Conventional Commit messages (`feat:`, `fix:`, `docs:` …).
- Never include meeting transcripts, API keys, `settings.json`, `vocabulary.txt` or `glossary.txt`.
